# Almaz TJ | Алмаз ТҶ

Барномаи Android барои ахбори футболи ҷаҳон бо интерфейси тоҷикӣ.

- Ахбор аз Google News RSS бо бахшҳои умумӣ, трансферҳо, клубҳо, бозингарон ва ҷустуҷӯи рӯзноманигорон.
- Тарҷумаи сарлавҳаҳо ба тоҷикӣ тавассути Google Translate endpoint (дастрасии endpoint кафолат дода намешавад).
- Навсозии худкор ҳар 3 дақиқа ва нигоҳдории ахбори охирин дар дастгоҳ.
- Манбаи хабар ва истинод ба мақолаи аслӣ.
- Натиҷаҳои зинда, ҷадвали бозиҳои пахшшаванда ва Matchora embed.

## Маҳдудиятҳои маълумот
Google News RSS агрегатор аст, на API-и расмии Fabrizio Romano ё клубҳо. Аз ин рӯ пайдо шудани хабар вобаста ба индексатсия ва нашри манбаи аслӣ аст. Matchora танҳо маълумоти бозӣ/канал ва плеери embed медиҳад. Барои хабарҳои фаврии кафолатнок, push notification ва маълумоти мукаммали трансфер провайдери дорои API ва иҷозатнома зарур аст.
