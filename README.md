# Almaz TJ

Барномаи Almaz TJ барои хизматрасониҳои рақамии бозӣ бо интерфейси тоҷикӣ.

## Қисмҳои барнома
- Асосӣ ва рӯйхати бозиҳо
- Free Fire, PUBG Mobile ва категорияҳои дигар
- Фармоишҳо ва таърихи фармоиш
- Ҳамён ва амалиётҳои баланс
- Профили корбар ва танзимот

## Ҳолати пайвастшавӣ
Интерфейси Flutter дар барнома мавҷуд аст. Барои фаъол шудани пуркунии автоматӣ, пардохт, рақами ягонаи корбар ва таърихи воқеии фармоишҳо бояд API-и сервер ва провайдерҳои пардохт/донат пайваст ва санҷида шаванд. Интерфейс ин имкониятҳоро худ аз худ таъмин намекунад.

## Build
`flutter pub get`
`flutter analyze`
`flutter test`
`flutter build apk --release`
`flutter build appbundle --release`
